# Source register and third-party image status

This folder retains 16 manufacturer screen illustrations for attributed visual comparison.
They are reference evidence, separate from the application's runtime assets and generated previews.
The project's MIT licence covers our authored descriptions and gallery code; it does not relicense
manufacturer screenshots, graphical artwork, trademarks or manual illustrations. No open
redistribution licence was established for these images. Their authors/rights holders retain their
rights. Product incorporation or other reuse requires its own rights determination.

The user explicitly requested a retained screen library and Git publication on 2026-10-06.
This is a bounded commentary collection, not a mirror of the manuals or an artwork pack.
Only the selected figures are retained; full manuals, downloads and extraction tools are outside Git.

## Acquisition and review

Direct PNGs keep the downloaded bytes. One Yamaha DM7 JPEG is converted to PNG
without cropping or resizing. PDF illustrations are extracted as complete embedded figures,
with RGB conversion when required. None are generated, sharpened, redrawn or upscaled.
Every selected image was individually opened and inspected before its description was written.
A final contact sheet checks the retained figures. Raw source and stored-image hashes, dimensions,
page numbers and PDF xrefs are in [manifest.json](manifest.json). A screenshot's enclosing manual
version and any older visible build/filename are recorded separately where known.

Observations are original visual analysis. Any cited workflow context is bounded to the named
manufacturer source. No commercial console software was installed or operated; no physical
audio, lighting, MIDI, DMX or transport acceptance is implied. Source links may later change;
the local image and hash identify exactly what was reviewed.
